# تطبيق إدارة النادي الرياضي والاشتراكات بلغة Flutter 🏋️‍♂️

تطبيق كامل مبني بأحدث إصدارات **Flutter & Dart** لإدارة الصالات الرياضية، المشتركين، مسح الباركود و QR Code، متابعة سجلات الحضور اليومية، وإرسال التنبيهات مع مزامنة سحابية كاملة عبر **Supabase**.

---

## 📱 الميزات الرئيسية للتطبيق (Features)

1. **لوحة القيادة والإحصائيات (Dashboard)**:
   - بطاقات إحصائية تفاعلية (إجمالي المشتركين، نسبة النشطين، حضور اليوم، الاشتراكات المنتهية والتي على وشك الانتهاء).
   - توزيع المشتركين حسب الرياضة (Gym, Boxing, Swimming, Fitness, Yoga, إلخ).
   - شريط الاشتراكات التي أوشكت على الانتهاء مع إمكانية التجديد بضغطة زر.
   - قائمة بآخر تسجيلات الحضور المسجلة بالوقت والتاريخ.

2. **إدارة المشتركين (Members Management)**:
   - إضافة وتعديل وحذف المشتركين.
   - البحث الذكي بالاسم، رقم الهاتف، أو كود الباركود.
   - تصفية حسب نوع الرياضة أو حالة الاشتراك (نشط / منتهي).
   - زر مباشر للتواصل عبر **WhatsApp** بنص جاهز ومخصص للمشترك.
   - تجديد فوري للاشتراك (+ شهر، + 3 أشهر، + سنة).
   - عرض بطاقة الباركود و QR Code الرقمية للمشترك.

3. **ماسح الباركود والـ QR Code (Camera Scanner)**:
   - مسح مباشر وسريع باستخدام كاميرا الهاتف (`mobile_scanner`).
   - دعم تشغيل فلاش الكاميرا والتبديل بين الكاميرا الأمامية والخلفية.
   - حقل إدخال يدوي في حال تعذر القراءة البصرية أو استخدام ماسح باركود خارجي (USB / Bluetooth).
   - استجابة فورية: بطاقة خضراء لتأكيد الحضور، أو بطاقة حمراء للتحذير من انتهاء الاشتراك مع زر تجديد فوري.

4. **سجل الحضور اليومي (Attendance Logs)**:
   - تسجيل وقت وتاريخ دخول المشتركين بدقة.
   - تصفية السجل حسب اليوم، أو حسب أي تاريخ مخصص، أو عرض السجل كاملاً.
   - إمكانية حذف تسجيل أو مسح السجل كاملاً.

5. **نظام التنبيهات والإشعارات (Notifications)**:
   - فحص آلي لتواريخ انتهاء الاشتراكات وتنبيه الإدارة قبل 3 أيام من الانتهاء وعند انتهائها.
   - عداد الإشعارات غير المقروءة في شريط التنقل.
   - إمكانية تحديد الإشعارات كمقروءة أو مسحها.

6. **الإعدادات والربط مع Supabase (Settings & Cloud Sync)**:
   - تخصيص اسم النادي، رقم الواتساب، والبريد الإلكتروني.
   - إدارة الرياضات والأنشطة (إضافة، تعديل، حذف مع نقل المشتركين للرياضة البديلة).
   - فحص الاتصال بقاعدة بيانات **Supabase** السحابية.
   - رفع البيانات المحلية للـ Cloud أو جلب البيانات الحية من Supabase.
   - نسخ استعلام SQL Schema الجاهز لإنشاء الجداول بنقرة واحدة.

## 🚀 كيفية تشغيل تطبيق Flutter محلياً

### 1. المتطلبات الأساسية
- تثبيت **Flutter SDK** (الإصدار 3.0 فما فوق): [flutter.dev](https://flutter.dev)
- تثبيت **Android Studio** أو **VS Code** مع إضافة Flutter & Dart.

### 2. تثبيت الحزم والمكتبات
افتح الطرفية (Terminal) في مجلد `flutter_app` وقم بتنفيذ:
```bash
cd flutter_app
flutter pub get
```

### 3. تشغيل التطبيق
قم بتوصيل هاتفك أو تشغيل المحاكي (Emulator):
```bash
# للتشغيل على Android أو iOS أو Chrome:
flutter run
```

## 📷 إعدادات أذونات الكاميرا (Camera Permissions)

### لنظام Android (`android/app/src/main/AndroidManifest.xml`):
```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-permission android:name="android.permission.CAMERA" />
    <uses-feature android:name="android.hardware.camera" />
    <uses-feature android:name="android.hardware.camera.autofocus" />
    ...
</manifest>
```

### لنظام iOS (`ios/Runner/Info.plist`):
```xml
<key>NSCameraUsageDescription</key>
<string>يحتاج التطبيق إذن الوصول للكاميرا لمسح باركود و QR المشتركين لتسجيل الحضور.</string>
```
